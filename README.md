# homebrew-gearprice

[![License](https://img.shields.io/badge/license-MIT-green)](https://github.com/woksin/gearprice/blob/main/LICENSE)

Homebrew tap for [gearprice](https://github.com/woksin/gearprice): see what guitar gear costs on Reverb right now, and what class it sits in.

```bash
brew tap woksin/gearprice
brew trust woksin/gearprice   # Homebrew 6 gates third-party taps
brew install gearprice
```

Or in one step: `brew install woksin/gearprice/gearprice`.

`Formula/gearprice.rb` is written by the release workflow in the [gearprice](https://github.com/woksin/gearprice) repository. Do not edit it by hand.

Usage, options and documentation live in the [main repo](https://github.com/woksin/gearprice).
